# Changelog

## 2.3.0

- Publish the modern Tauri/React/Rust application source under GPLv3.
- Add Windows x64 NSIS and Store MSIX packaging, plus Ubuntu-baseline Linux AppImage/DEB builds.
- Add Vulkan speech-recognition acceleration with portable CPU/AVX2 fallback and RAM-aware settings.
- Show automatically detected source-language names.
- Offer online MyMemory and optional offline language-direction translation packs, preserving source timestamps and exports.
- Improve ten-language UI, themes, RTL, icon clarity and stationary dropdown/tab transitions.
- Document privacy, third-party software, contributions and Store submission.

Earlier Python releases remain in repository history and existing release tags. They are no longer the maintained application.
