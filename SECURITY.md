# Security

Report a security vulnerability through [GitHub's private vulnerability reporting](https://github.com/idginity124/VidExtract/security/advisories/new) when available. Do not place credentials, private media or exploit details in a public issue. If private reporting is unavailable, open a minimal issue requesting a private contact without posting the vulnerability itself.

The current 2.x desktop line receives fixes. The retired Python application is not maintained. Dependencies and native tools are updated through reviewed builds; always download packages from this repository's releases or the official Microsoft Store listing once published.
